# AI Resume Analyzer and Job Recommendation System

## Project Description

This project analyzes a user's resume and recommends suitable job roles based on the skills present in the resume.

## Features

* PDF/DOCX Resume Upload
* Resume Text Extraction
* Skill Extraction
* Job Role Matching
* Match Score Calculation
* Top 3 Job Recommendations
* Skill Gap Analysis
* Learning Roadmap Generation

## Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-Learn
* PyPDF
* Python-Docx

## How to Run

1. Install dependencies:

pip install -r requirements.txt

2. Run the application on an available port:

python -m streamlit run app.py --server.headless true --server.port 8502

> Port 8501 was already in use in this environment, so the verified working port for this project is 8502.
